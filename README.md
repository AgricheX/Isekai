## English

### What it adds

- 8 new races: Ancient China, Androids, Angels, Beastmen, Dark Elves, Demonic, Gnomes and Japanese, each with its own buildings and banners.
- Creatures: Dragon Slayer, Dark Knight, Demon King, Griffins, Phoenix, Trolls, Witch and Godzilla.
- Japanese units: soldiers, tanks and helicopters.
- 16 new weapons, including guns.
- New traits and kingdoms.
- Invasions.

### How to install

1. Install NCMS for WorldBox 0.22 / 0.23.
2. Download **Isekai.zip** with the link above.
3. Extract it into the `Mods` folder of your WorldBox installation, so you get `Mods/Isekai/mod.json`.
4. Start the game.

## Português (Brasil)

### O que o mod adiciona

- 8 raças novas: China Antiga, Androides, Anjos, Homens-Fera, Elfos Negros, Demoníacos, Gnomos e Japoneses, cada uma com construções e bandeiras próprias.
- Criaturas: Matador de Dragões, Cavaleiro Sombrio, Rei Demônio, Grifos, Fênix, Trolls, Bruxa e Godzilla.
- Unidades japonesas: soldados, tanques e helicópteros.
- 16 armas novas, incluindo armas de fogo.
- Traços e reinos novos.
- Invasões.

### Como instalar

1. Instale o NCMS para o WorldBox 0.22 / 0.23.
2. Baixe o **Isekai.zip** pelo link acima.
3. Extraia na pasta `Mods` do WorldBox, de forma que fique `Mods/Isekai/mod.json`.
4. Abra o jogo.

### Ajuda

Dúvidas e bugs: [Agriche Community no Discord](https://discord.gg/s3EbgNSsJW).
